# K2 Family Office PC版テストサイト

[テストサイトを開く](https://makiringgg.github.io/k2-family-office-preview/)

2026年10月21日承認版。CTA4か所のホバー色は #d5c8a0。FAQ7項目はテキストと開閉式アコーディオン。画像は原寸を保った可逆圧縮で、画面外の画像を遅延読み込みします。暗い背景と移動速度1.95を維持しています。

QはリュウミンBold 22px、AはヒラギノW5 20px／行間40px（PC基準）。指定フォントが未導入の端末では代替書体を使用します。フォントファイルは配布していません。

CTAリンク先は未定です。index.htmlと同じフォルダに画像・CSS・JavaScriptを配置して閲覧してください。検索エンジン向けnoindex設定あり。公開URLは誰でも閲覧できます。
